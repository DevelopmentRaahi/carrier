Role :

This is a full-time Backend Web Developer role based in Noida. As a Backend Web Developer at Domgys, you will be responsible for developing and maintaining the server-side logic of our websites and web applications. Your day-to-day tasks will involve collaborating with cross-functional teams, designing and implementing APIs, ensuring high-performance and responsiveness, and optimizing code for scalability and security. Join our dynamic team and contribute to the digital transformation of businesses.

Qualifications :
  • 1-2 years of Proven experience as a Backend Web Developer or similar role
  • Strong proficiency in programming languages such as Java, Python, or Ruby
  • Experience with server-side frameworks such as Node.js, Django
  • Understanding of front-end technologies and platforms, such as HTML, CSS, and JavaScript
  • Proficient and working knowledge of API connection, set up and configuration of API with third party websites, DB's , App's and Registry Systems
  • Experience with relational databases and SQL
  • Familiarity with version control systems (e.g., Git)
  • Knowledge of security best practices and web application vulnerabilities
  • Excellent problem-solving and troubleshooting skills
  • Ability to work collaboratively in a team environment
  • Bachelor's degree in Computer Science or a related field (or equivalent work experience)
